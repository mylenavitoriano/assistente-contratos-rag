# Contratos de exemplo

Contratos mock fornecidos com o desafio, dos empreendimentos fictícios
*Residencial Jardins do Vale* e *Condomínio Vista Verde*. Compradores, CPFs e
demais dados são fictícios.

São a massa de teste do pipeline de indexação e do retrieval. Embora sigam o
mesmo modelo de contrato, os valores divergem entre eles — multa de distrato,
prazo de garantia, percentual de entrada — o que exige que a busca localize o
contrato certo, e não apenas a cláusula certa.

A aplicação também aceita novos PDFs via upload na interface.
